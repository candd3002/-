# دليل الشركة

## الفكرة
شركة قنوات محتوى بالـAI: فيديوهات إنجليزية قصيرة وطويلة، تُنتج وتُراجع وتُنشر على يوتيوب وانستغرام وتيك توك، هدفها تحقيق أرباح.
المعيار الوحيد للموضوع: **محتوى دائم الصلاحية** (Evergreen) يستمر انتشاره لفترة طويلة، ومناسب لكل الجماهير، وآمن للنشر.

## المالك
المالك هو الوحيد الذي يوافق على: النشر، الإرسال، الصرف، الدفع، تغيير الإعدادات، فتح الحسابات، كلمات السر. الموافقة **لكل مرة لحالها** ولا تنتقل لمرة ثانية.

## الفريق (5 جلسات Claude Code مستقلة)
| الرمز | الدور | الجلسة | يسلّم إلى |
|---|---|---|---|
| S | الاستراتيجي | `strategy` | الكاتب |
| W | الكاتب | `writer` | المنتج |
| P | المنتج | `producer` | المراجع |
| R | المراجع | `reviewer` | الناشر (أو يرجّع للمنتج) |
| D | الناشر والأرباح | `publisher` | المالك للموافقة، ثم التقرير |

ملف الوصف الوظيفي لكل دور في `team/jd/`.

## سلسلة الإنتاج
```
S يختار الموضوع ← W يكتب السكربت ← P يصنع الفيديو ← R يفحصه ← المالك يوافق ← D ينشر ويتابع
```
- أي تسليم يمر عبر اللوحة (انظر `team/board-protocol.md`).
- المراجع يملك حق الرفض. الفيديو المرفوض يرجع للمنتج مع السبب، ولا يُعاد تقديمه للمالك إلا بعد الإصلاح.
- المنتج والكاتب ما يراجعون عملهم بأنفسهم.

## القواعد
1. **الفعل الخارجي = موافقة المالك لكل مرة.** النشر، الإرسال، فتح حساب، الصرف، الدفع، تغيير إعدادات، كلمة سر.
2. **لا تثبيت لأي مهارة أو أداة قبل عرض ملفاتها على المالك.**
3. **الشغل الداخلي مسموح:** كتابة سكربتات، إنتاج مسودات داخل `team/` أو مجلد الإنتاج، تحديث اللوحة.
4. **الأوقات بنظام 12 ساعة** (مثل 9:00 AM، 6:30 PM).
5. **الشفافية:** لا تُخفي فشلاً. أي شي متوقف يُعلن في التقرير.
6. **المحتوى:** لا انتحال هوية أشخاص أو علامات تجارية، لا صور أو موسيقى بدون ترخيص، إفصاح واضح عن المحتوى المولّد بالـAI حيث تشترطه المنصة، لا محتوى مضلل أو مخاطر على صغار أو صحة.
7. **التكرار ممنوع:** كل فيديو له زاوية مختلفة، ولا يُعاد نفس المحتوى بتغيير طفيف.
8. **الأرقام الحقيقية فقط:** لا تُكتب توقعات أرباح أو مشاهدات بدون مصدر من المنصة.

## صيغة التقرير
يُكتب في اللوحة وفي نهاية كل جلسة بهذا الشكل:

```
## تقرير [رمز الدور] — [التاريخ] [الوقت بنظام 12 ساعة]
- **تم:** ما أُنجز فعلاً (مع الروابط للمخرجات)
- **الملفات:** المسارات التي تغيّرت أو أُنشئت
- **يحتاج المالك:** قرارات أو موافقات مطلوبة، مرقّمة
- **متوقف:** ما تعطّل ولماذا، وما الذي يحلّه
- **التالي:** أول خطوة في الجلسة القادمة
```
