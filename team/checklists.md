# قوائم «خلص» لكل مرحلة

## 1. الاستراتيجية (S)
- [ ] الموضوع دائم الصلاحية (يبقى مفيداً بعد شهور).
- [ ] الزاوية والجمهور والسبب مكتوبة.
- [ ] لا تكرار مع الأرشيف.
- [ ] مهمة الكاتب في اللوحة بحالة `ready`.

## 2. الكتابة (W)
- [ ] hook في أول 3 ثوانٍ.
- [ ] السكربت خالٍ من الادعاءات الكاذبة أو الوعود المالية.
- [ ] نسخ حسب المنصة (طول الشورت غير طول الطويل).
- [ ] العنوان والوصف والهاشتاقات موجودة.
- [ ] ملاحظات الإنتاج كافية.
- [ ] حالة المهمة `script-done`.

## 3. الإنتاج (P)
- [ ] الفيديو مطابق للسكربت.
- [ ] الصوت واضح، والترجمات متزامنة.
- [ ] كل عنصر خارجي مرخّص وموثّق المصدر.
- [ ] المقاس والمدة مناسبان للمنصة.
- [ ] `notes.md` مكتمل.
- [ ] الأدوات المستخدمة كلها معتمدة من المالك.
- [ ] حالة المهمة `video-done`.

## 4. المراجعة (R)
- [ ] كل بنود قائمة الفحص مُعلَّمة.
- [ ] الإفصاح عن الـAI موجود حيث يلزم.
- [ ] الترخيص والمصادر موثّقة.
- [ ] لا تكرار جوهري.
- [ ] القرار مكتوب بسبب: موافق، أو يُرجَع، أو يُرفع للمالك.

## 5. النشر (D)
- [ ] حزمة النشر معروضة في `needs` بحالة «ينتظرك».
- [ ] موافقة المالك على هذه الحزمة بالذات موجودة.
- [ ] بعد النشر: الرابط مسجّل في `log.md` وفي اللوحة.
- [ ] أرقام الأسبوع مأخوذة من المنصة مع تاريخ السحب.
- [ ] تقرير الأرباح مكتوب بالفصل بين المؤكد والمتوقع.

## 6. الإغلاق اليومي (كل قسم)
- [ ] تقرير بالصيغة المعتمدة في آخر الجلسة.
- [ ] اللوحة محدّثة لكل مهمة لمستها.
- [ ] كل شي متوقف له سبب ومالك للحل.
