# مؤشر سحب السيولة + الترند (ربح:خسارة 1:2)

الملف: `liquidity_sweep_trend_rr.pine` (Pine Script v5)

## طريقة التشغيل على TradingView
1. افتح TradingView ← Pine Editor.
2. الصق محتوى الملف واضغط **Add to chart**.
3. من الإعدادات فعّل التنبيهات (Alerts) للإشارات BUY / SELL.

## منطق المؤشر
1. **القمم والقيعان:** تُحسب بـ `ta.pivothigh / ta.pivotlow` وتتأكد بعد عدد شموع محدد (Pivot Length).
2. **الترند:** هيكل السوق
   - HH + HL = ترند صاعد
   - LH + LL = ترند هابط
   - غير ذلك = Range
   ومعه EMA50/EMA200 كتأكيد إضافي.
3. **سحب السيولة:**
   - شراء: الفتيل ينزل تحت آخر قاع ثم يغلق الشمعة فوقه.
   - بيع: الفتيل يصعد فوق آخر قمة ثم يغلق الشمعة تحتها.
4. **لا دخول مباشرة على شمعة السحب.** المؤشر ينتظر **تأكيداً** (إغلاق يكسر القمة/القاع السابق للسحب) خلال عدد شموع محدد. هذا هو قرار الشراء/البيع.
5. **الاستمرار:** في ترند واضح، كسر القمة/القاع بإغلاق يعطي إشارة استمرار (BOS).
6. **الوقف:** خلف فتيل السحب (أو خلف القاع/القمة) + بافر ATR.
7. **الهدف:** دائماً = 2 × المخاطرة (1:2). إذا كانت المخاطرة أكبر من حد ATR المحدد تُتجاهل الصفقة.
8. صفقة واحدة مفتوحة في كل مرة. عند ضرب الوقف أو الهدف تُحسب في لوحة الإحصائيات.

## حدود مهمة
- الـ 1:2 مضمونة **بالحساب** في كل صفقة، لكن **نسبة النجاح ليست مضمونة**. الربح يعتمد على نسبة النجاح الفعلية. مع 1:2 يكفي تقريباً نجاح 34% ليكون التوقع موجباً قبل العمولة والانزلاق، لكن هذا يحتاج إثبات بالباك تيست.
- إذا ضُربت الشمعة الواحدة بالوقف والهدف معاً يُحسب خسارة (افتراض متحفظ).
- يجب اختبار المؤشر على بيانات تاريخية (Strategy Tester) وعلى حساب تجريبي قبل أي استخدام بمال حقيقي.
- هذا ليس نصيحة مالية.

## ما يحتاج منك
- إرسال المؤشر الحالي الذي عندك (ملف Pine أو نسخة الكود) إذا كان موجوداً، حتى أدمج منطقه بدل بناء جديد.
- تحديد الأصول والفريم المستهدف (مثلاً BTC 1H أو XAUUSD 15m) لضبط الإعدادات.
