# Hamoody 1M — مؤشرك مع طبقة معلومات السيولة والترند

الملف الوحيد: `Hamoody_1M.pine` (Pine Script v5).

- إشاراتك ومربعاتك وSL/TP وتنبيهات الـ webhook **كما هي حرفياً** من كودك الأصلي.
- المضاف **معلومات فقط** لا تغيّر أي إشارة: الترند من القمم والقيعان، سحب السيولة مقابل الكسر الحقيقي، حكم تحت كل إشارة، ونتيجة كل كسر (صمد أم كان كاذباً)، وأفكار انعكاس بعد السحب.
- كل الإضافات تُطفأ من مجموعات الإعدادات التي تبدأ بـ `Info -`.
