# Hamoody 1M — مؤشرك المحدّث

الملف الوحيد: `Hamoody_1M.pine` (Pine Script v5). هو مؤشرك الأصلي بكل أقسامه ومدخلاته، مع محرك سحب السيولة والترند مضافاً عليه.

- المحرك يُشغَّل/يُطفأ من الإعداد **Enable Liquidity Sweep + Trend Engine**. عند الإطفاء يعود المؤشر لسلوكه الأصلي (الإشارات وSL/TP).
- رسالة الـ webhook لم تتغير: `(BUY|SELL) Signal - Hamoody v4, Close, TP, SL, Time`.
- ليس نصيحة مالية. اختبر على بيانات تاريخية قبل أي مال حقيقي.
